

## Vibe Coding 应用分类方案

### 现状分析
当前应用只有自由标签（`tags` 字段），没有统一的业务领域分类。首页仅按热门/最新/可购买排序，缺乏按领域浏览的能力。

### 推荐分类体系

为 Vibe Coding 应用设计以下 **业务领域分类**（`category`）：

```text
┌─────────────────────────────────────────────┐
│  分类名称          │  说明                    │
├─────────────────────────────────────────────┤
│  工具效率 Tools     │  生产力工具、自动化       │
│  AI 智能 AI        │  AI 聊天、图像生成等      │
│  内容创作 Content   │  写作、设计、视频         │
│  商业营销 Business  │  营销、CRM、电商          │
│  教育学习 Education │  课程、练习、知识库       │
│  生活娱乐 Lifestyle │  游戏、社交、健康         │
│  开发者 Developer   │  API、DevOps、代码工具   │
│  数据分析 Data      │  报表、可视化、BI         │
│  其他 Other         │  未归类                   │
└─────────────────────────────────────────────┘
```

### 实现方案

#### 1. 数据库变更
- 在 `apps` 表新增 `category` 字段（text 类型，默认 `'other'`）
- 不使用 enum，方便后续扩展

#### 2. 前端 — 首页分类导航
- 在现有 热门/最新/可购买 tabs 下方，增加一排**分类筛选标签**（横向滚动的 Badge/Chip）
- 点击分类后，过滤该类别的应用；支持与现有排序 tab 组合使用
- 增加"全部"选项，默认选中

#### 3. 提交页面
- 在 Submit 表单中增加**分类选择器**（Select 下拉），必选项
- 智能解析时尝试根据网站内容自动推断分类（通过 parse-url 的描述和标签匹配关键词）

#### 4. 管理后台
- 审核页面可查看和修改应用分类
- 批量提交时自动根据解析结果推断分类

#### 5. 多语言支持
- 在所有 7 个语言文件中增加分类名称的翻译

### 涉及文件
- **数据库迁移**: 新增 `category` 列
- `src/pages/Index.tsx`: 增加分类筛选 UI 和查询逻辑
- `src/pages/Submit.tsx`: 增加分类选择器
- `src/pages/admin/AdminDashboard.tsx`: 审核中显示/编辑分类
- `supabase/functions/parse-url/index.ts`: 尝试自动推断分类
- `src/i18n/locales/*.json`: 7 个语言文件增加分类翻译
